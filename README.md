# SUM BINGO

숫자 합성 덱빌딩 빙고 게임 — 로컬 2인용(한 화면, 번갈아 플레이) 프로토타입.

카드 3장을 조합해 합을 만들고 자신의 빙고판 숫자를 호명합니다. 일반 호명은 양쪽 플레이어에게 동시에 적용되고, 손패 3장을 모두 사용하면 보너스턴에 진입해 나만 체크하거나 상대의 체크를 취소할 수 있습니다. 먼저 빙고 3줄을 완성하면 승리합니다.

## 실행 방법

빌드 도구 없이 순수 HTML/CSS/JS(ES 모듈)로 작성되어 있습니다. ES 모듈은 `file://`로 직접 열면 CORS 제약으로 동작하지 않으므로, 로컬 정적 서버로 실행하세요.

```bash
python3 -m http.server 8080
# 또는
npx serve .
```

브라우저에서 `http://localhost:8080` 접속.

## 진행 상태

기획안(`docs`에 명시된 규칙)의 1단계(핵심 규칙)를 전부 구현했고, 2단계(사용성) 중 다음 항목을 포함합니다.

- 유효한 호명 합계 미리보기 및 빙고 칸 강조
- 보너스턴 합계에 해당하는 칸 강조(내 미체크 숫자 / 상대 체크된 숫자)
- 게임 로그
- 턴 안내 배너
- 턴 교대 시 "기기 넘기기" 화면(상대 손패 비공개)

AI 대전, 온라인 대전, 애니메이션/사운드 연출 등 3단계 확장 기능은 포함하지 않았습니다.

## 코드 구조

- `src/config.js` — 상수, 게임 단계(GAME_PHASE), 빙고 라인 좌표
- `src/gameLogic.js` — 순수 게임 로직(보드/시장 생성, 카드 사용, 보너스턴, 빙고 판정, 승리 판정)
- `src/ui.js` — 상태를 DOM으로 렌더링
- `src/main.js` — 이벤트 위임 및 턴 흐름 제어
